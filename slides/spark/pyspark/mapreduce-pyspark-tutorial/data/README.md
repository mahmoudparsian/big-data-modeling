# data

Synthetic retail dataset used by `mapreduce-pyspark-notebook.ipynb` (and mirrored by the generation code in `mapreduce-pyspark-tutorial.md`). Generated by [`../generate_retail_data.py`](../generate_retail_data.py) — deterministic (seed=7); re-running the script reproduces these files exactly. Regenerate with `python3 ../generate_retail_data.py` if these files are ever removed.

## Contents

| Name | Type | Description |
|---|---|---|
| [`customers.csv`](customers.csv) | csv | 200 rows: `customer_id, country, segment` |
| [`products.csv`](products.csv) | csv | 50 rows: `product_id, sku, category, price` |
| [`orders.csv`](orders.csv) | csv | 1,000 rows: `order_id, customer_id, order_date, channel` |
| [`items.csv`](items.csv) | csv | 2,455 rows: `order_id, product_id, quantity, unit_price` (1-4 line items per order) |
