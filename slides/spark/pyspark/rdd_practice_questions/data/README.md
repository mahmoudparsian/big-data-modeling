# Data for the RDD Practice Questions

Small text input files for the RDD practice questions
([Set 01](../QUESTIONS_01.md)).

| File | Used in | Format |
|---|---|---|
| [sales.txt](sales.txt) | Q4 | `store,product,price` (10 lines) |
| [movie_ratings.txt](movie_ratings.txt) | Q6 | `user,movie,rating` (12 lines) |
| [web_logs.txt](web_logs.txt) | Q7 | `date,user,url,http_status` (14 lines) |
| [temperatures.txt](temperatures.txt) | Q8 | `city,date,temp_c` (14 lines, including a header, an empty line, an `NA` value, and a record with a missing field, all on purpose) |
| [purchases.txt](purchases.txt) | Q9 | `customer,category,product` (15 lines) |
