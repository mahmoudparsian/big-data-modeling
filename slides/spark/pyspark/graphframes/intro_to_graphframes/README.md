# intro_to_graphframes

Slides and third-party reference PDFs introducing graphs and
GraphFrames in Spark: Mahmoud Parsian's own numbered intro decks
(`9.1`–`9.3`), plus a large collection of external slide decks and
articles kept for further reading.

## Mahmoud Parsian's own decks

| Name | Description |
|---|---|
| [`9.1_introduction_to_graphs.pptx`](9.1_introduction_to_graphs.pptx) | Introduction to graphs (data structure fundamentals) |
| [`9.2_introduction_to_GraphFrames.pptx`](9.2_introduction_to_GraphFrames.pptx) | Introduction to GraphFrames |
| [`9.3_GraphFrames_API_and_Tutorials_and_Videos.pptx`](9.3_GraphFrames_API_and_Tutorials_and_Videos.pptx) | GraphFrames: API, documentation, tutorials, and videos — a pointers/further-reading deck |
