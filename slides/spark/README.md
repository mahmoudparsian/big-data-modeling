# Spark

Slides, tutorials, and example code for teaching Apache Spark and PySpark.

## Contents

| Folder | Description |
|---|---|
| [`docs/`](docs/) | Third-party slide decks and PDFs introducing Spark, Spark internals, and MLlib (Databricks, Stanford, Spark Summit, and other external authors). |
| [`installation/`](installation/) | Notes and scripts for installing/building Spark on macOS, Linux, Windows, Google Cloud, and Amazon (EC2), plus troubleshooting notes (e.g. SSH port 22 issues). |
| [`pyspark/`](pyspark/) | PySpark tutorials and hands-on session materials: RDDs, DataFrames, joins, UDFs, GraphFrames, word count, Jupyter notebooks, Spark + LLM examples, and a `spark-submit` example ([`pyspark/spark-submit-example/`](pyspark/spark-submit-example/)). |

## Getting Started

If you're new to Spark, start with the slide decks in [`docs/`](docs/), then set up your environment using [`installation/`](installation/), and move on to the hands-on materials in [`pyspark/`](pyspark/).
