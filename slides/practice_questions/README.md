# Practice questions for exams

* MapReduce
* PySpark RDDs
* PySpark DataFrames
* GraphFrames

Split by topic into three files (as of 9/4/2026) so each paradigm can be
studied independently. Solutions are intentionally not in this repo — see
the instructor's private `practice_questions_solution/` folder.

| Name | Description |
|---|---|
| [`mapreduce_questions.md`](./mapreduce_questions.md) | Classic MapReduce practice questions (map()/reduce() pseudocode, HDFS/cluster fundamentals) |
| [`rdds_questions.md`](./rdds_questions.md) | PySpark RDD practice questions (transformations/actions, `reduceByKey`/`groupByKey`/`combineByKey`, etc.) |
| [`dataframes_questions.md`](./dataframes_questions.md) | PySpark DataFrame and GraphFrame practice questions |
