#  Amazon Athena

* Amazon Athena is an interactive query 
  service that makes it easy to analyze 
  data in Amazon S3 using standard SQL. 

* Amazon Athena is an interactive, serverless 
  query service provided by Amazon Web Services 
  (AWS) that allows you to analyze data directly 
  in Amazon S3 using standard SQL. 

* Athena is serverless, so there is no 
  infrastructure to manage, and you pay only 
  for the queries that you run.

* Because it is serverless, you do not need 
  to manage or set up any infrastructure, and 
  you pay only for the amount of data scanned 
  by your queries.

## Key Features

* No Infrastructure: No servers to configure, 
  patch, or manage.

* Standard SQL Support: Uses open-source distributed 
  engines (like Presto and Trino) to run ANSI SQL 
  queries, joins, and window functions.

* Direct S3 Integration: Queries data right where it 
  lives in Amazon S3 without needing an ETL process to 
  load it into a separate database.

* Supported Formats: Works with CSV, JSON, ORC, Avro, 
  Parquet, and more.

## Common Use Cases

* Analyzing raw logs stored in S3.

* Running ad-hoc business intelligence and data analytics.

* Connecting with external BI and visualization tools via JDBC/ODBC drivers.

* Executing federated queries across other relational and non-relational 
  data sources.
