# Big Data

Opening lecture unit: <br>

* What is Big Data? 
* Core Big Data concepts
* What are Big Data solutions?

## Technical Framing of Big Data

**For current teaching use, start with
[`2_introduction_to_big_data_and_solutions.md`](2_introduction_to_big_data_and_solutions.md)**
(or its rendered [PDF](2_introduction_to_big_data_and_solutions.pdf))
— an MD/MARP slide deck covering Big Data concepts and characteristics,
foundational distributed-systems concepts (CAP theorem, ACID vs.
BASE, horizontal vs. vertical scaling, data lake/warehouse/lakehouse,
partitioning, governance), the Big Data life cycle, and Big Data
solutions: MapReduce, Apache Hadoop, Apache Spark/PySpark, and Amazon
Athena.

## Non-Technical Framing of Big Data
For a shorter, non-technical framing of why Big Data matters, see
[`1_what_is_big_data_by_Bernard_Marr.pdf`](1_what_is_big_data_by_Bernard_Marr.pdf)
— a good on-ramp to read before the deck above.
