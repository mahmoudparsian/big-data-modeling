# Graph Data

Sample graph datasets (edge/vertex lists) used for GraphFrames and graph-algorithm exercises.

Source of Data: https://dhs.stanford.edu/gephi-workshop/sample-graph-data/

| Name | Description |
|---|---|
| [`graph_edges.txt`](./graph_edges.txt) | Small hand-built edge list |
| [`graph_vertices.txt`](./graph_vertices.txt) | Small hand-built vertex list (matches `graph_edges.txt`) |
| [`dh11_edges.csv`](./dh11_edges.csv) | Edge list from the Gephi workshop "DH11" sample graph |
| [`dh11_nodes.csv`](./dh11_nodes.csv) | Node list from the Gephi workshop "DH11" sample graph |
| [`p2p-Gnutella09.txt`](./p2p-Gnutella09.txt) | Gnutella peer-to-peer network snapshot (larger real-world graph) |
