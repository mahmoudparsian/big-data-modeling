# genes

Tiny gene-list dataset used in filtering/set-exclusion exercises.

## Contents

| Name | Type | Description |
|---|---|---|
| [`exclude.txt`](exclude.txt) | txt (35B) | Gene IDs to exclude/filter out (one per line) |
| [`genes.txt`](genes.txt) | txt (2.4KB) | Gene ID + measurement values, `gene_id,val1,val2,...` (variable number of values per gene) |
